# editing

A minimal, slim feature set, opinionated, all in one photo editing app for sports photography and photo journalism work,
built with Rust and GPUI. Sort of like a Photo Mechanic + Lightroom hybrid with a little Photoshop features too. Only features I want and need in my work, collected in one place instead of 3, and runs on Linux.

Small feature set: ingest from multiple cards, IPTC templates, code replacements, quick
edits, crop, ability to blur/mosaic faces, FTP/SFTP upload.

Status: Building sloppy PoC with agents to evaluate.
